Spectacle · storefront themes

The theme contract

Every creator storefront is themed to the creator's own medium — the page is the portfolio and an example of the craft. A theme is a preset chosen from this list, derived from the format the creator already declared. Creators never write CSS.

The one rule

Theme the stage. Never the rail.

The stage — changes per theme

Hero, reel, portfolio, background, ambient motion, display type. The creator's world.

The rail — byte-identical everywhere

Packages, prices, usage rights, total, Request booking, verification, the assurance line. Spectacle's chrome.

Rail is locked surface #1C1710 CTA #FFB24D Hanken Grotesk tabular $28,000 Request booking It carries its own background and floats on the theme — a dark rail on daylight concrete is the point. The contrast is the gallery-wall label.

Holds for every theme
AA on its own canvas

Stage text clears AA against the theme's own background. The rail is exempt by construction — it carries its own.

Beautiful when still

Each theme has a static reduced-motion variant. If a page only works while moving, the theme has failed.

One loop, paused off-screen

At most one ambient motion loop per page. It stops when scrolled away. Mobile is mandatory.
